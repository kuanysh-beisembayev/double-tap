# double-tap

Armlet double toggle for Dota 2.

1. In Dota 2 hotkeys, bind the Armlet slot to `X` (normal cast) and `K` (quickcast).
2. Download `double-tap-<version>.exe` from the [latest release](../../releases/latest) and run it.

`X` toggles once. `Alt+D` toggles twice.

If Windows blocks the exe, install [AutoHotkey v2](https://www.autohotkey.com/) and run `double-tap.ahk` from the release instead.
